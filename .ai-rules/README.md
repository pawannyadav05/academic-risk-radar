# AI Agent Rules

This folder contains configuration files that instruct AI coding assistants (Antigravity, Claude Code, Cursor, Windsurf, Copilot, etc.) on how to work with this repository.

| File | Purpose |
|---|---|
| `cursorrules.md` | Rules for Cursor & general AI agents — fetch latest code, read docs, feature-branch workflow |
| `CLAUDE.md` | Claude Code-specific instructions |

> These files enforce: pull-before-coding, docs-first development, feature-branch git workflow, and module boundary rules.
